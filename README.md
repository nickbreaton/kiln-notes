# Kiln Notes

Track pottery pieces through the creation process. Take photos and organize them by status: Drying, Bisquing, Glazed, and Complete.

## Development

This is an Astro + React application powered by Effect for state management and error handling.

| Command | Action |
| :------ | :----- |
| `bun install` | Installs dependencies |
| `bun dev` | Starts local dev server at `localhost:4321` |
